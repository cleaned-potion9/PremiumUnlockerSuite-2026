## FAQ

### Is OmniPatch safe to use on my computer?

OmniPatch is a locally-run Windows utility that modifies application files on your device only. It does not transmit data, connect to external servers, or require system-level drivers. We recommend scanning files with anticomponent software for your own peace of mind.

### Which specific AI applications does OmniPatch support?

OmniPatch is designed for ChatGPT (web app wrappers), Claude, Perplexity AI, Microsoft Copilot, GitHub Copilot, Cursor, Devin, and JetBrains AI Assistant. It targets their desktop clients or specific local installation components.

### How often is OmniPatch updated to support new versions of AI tools?

Updates are typically released within 24-48 hours after a major update to a supported AI application is deployed, ensuring continued compatibility and feature access.

### Will using OmniPatch get my account banned by the AI service providers?

OmniPatch modifies the local client software. While it aims to be undetectable, any modification of client software carries a theoretical risk of account review or limitation by the service provider. Use at your own discretion.

### Do I need an internet connection for OmniPatch to work?

No, OmniPatch operates entirely offline. The activation is applied locally to the installed application files. An internet connection is only needed to download the patcher and the AI applications themselves.

### Can I use OmniPatch on multiple computers?

Yes, you can run the patcher on as many Windows computers as you like. The activation is applied to each machine's local installation independently.

### Does OmniPatch work with the latest Windows 11?

Yes, OmniPatch is fully compatible with Windows 10 and Windows 11 (both x64 and ARM versions). It runs as a standard user-level application.

### What happens if a supported AI application releases a major update?

You may need to re-run the OmniPatch activator after a major application update. The patcher includes a check and will notify you if re-activation is required.
